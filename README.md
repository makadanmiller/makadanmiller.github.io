# Makada Miller portfolio website

A responsive, dependency-free GitHub Pages site using the professional headshot supplied for this project. This repo contains the public website only, not the separate GitHub profile README.

## Preview locally

Open `index.html` in your browser, or run a simple local HTTP server:

```bash
python3 -m http.server 8000
# Then visit http://localhost:8000
```

## Deploy

Publish this folder's contents to the `makadanmiller.github.io` repository. Set GitHub Pages to publish from `main` at `/(root)`.

## Edit

- Update copy, projects, and experience in `index.html`.
- Customize colors in `styles.css` under `:root`.
- Replace your portrait with another PNG at `assets/headshot.png`.

Planned projects are labeled clearly. Add working links only once each repo exists and contains tested, original work.
